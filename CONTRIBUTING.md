# Contributing to QM2

First off, thank you for considering contributing to **QM2**! It’s people like you who make open-source tools better for everyone. 

Whether you are fixing a bug, improving documentation, or suggesting new features, your help is highly appreciated.

---

## 🚀 How Can I Contribute?

### 1. Reporting Bugs
* Check the [Issues](https://github.com/ahalvadzija/qm2/issues) page to see if the bug has already been reported.
* If not, open a new issue. Include:
    * A clear, descriptive title.
    * Steps to reproduce the problem.
    * Your OS and Python version.
    * Any relevant error logs or screenshots.

### 2. Suggesting Enhancements
* Open an issue with the tag `enhancement`.
* Explain why this feature would be useful and how it should work.

### 3. Pull Requests (PRs)
* **Branching**: Use a descriptive branch name like `feat/new-quiz-format` or `fix/logic-error`.
* **Testing**: Ensure that all tests pass before submitting. We aim to maintain our **86%+ coverage**.
* **Linting**: We use **Ruff** for code quality. Please run `ruff check .` before committing.
